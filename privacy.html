Política de privacidad

Última actualización: septiembre de 2026.

video-channels es una herramienta de línea de comandos de uso personal. Su único usuario es su autor, que la emplea para consultar las estadísticas de sus propios canales de YouTube. No se ofrece a terceros.

Qué datos se utilizan

Con la autorización explícita del titular de la cuenta y con permisos de solo lectura, la herramienta accede a:

  • Datos de YouTube Analytics de los canales del propio usuario: retención de audiencia, impresiones, porcentaje de clics (CTR), duración media de visionado, fuentes de tráfico y términos de búsqueda.
  • Metadatos de los vídeos del propio usuario (título, fecha de publicación y duración) mediante la API de YouTube Data v3.

Cómo se utilizan

Los datos se descargan al ordenador local del usuario y se guardan en archivos locales (CSV y JSON) para su análisis. No se comparten con terceros, no se publican, no se transfieren a ningún servidor externo y no se usan con fines publicitarios ni de elaboración de perfiles.

Almacenamiento y conservación

El token de acceso de OAuth se guarda únicamente en la carpeta local del equipo del usuario. Puede revocarse en cualquier momento desde la configuración de la cuenta de Google. Los archivos de datos los conserva o elimina el propio usuario en su equipo.

Uso de datos de la API de Google

El uso de la información recibida de las API de Google por parte de esta herramienta se ajusta a la Política de Datos de Usuario de los Servicios de la API de Google, incluidos sus requisitos de uso limitado.

Terceros

La herramienta se comunica exclusivamente con las API de Google y de YouTube. No existen otros destinatarios de los datos.
